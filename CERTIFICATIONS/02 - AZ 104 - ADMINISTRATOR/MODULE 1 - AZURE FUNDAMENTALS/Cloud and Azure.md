## Core Cloud Concepts
Cloud computing is the delivery of computing services over the Internet ("the cloud") to offer faster innovation, flexible resources, and economies of scale. 

**Key Characteristics:**
* **High Availability & Reliability:** Ensures services are accessible when needed, often backed by Service Level Agreements (SLAs).
* **Scalability & Elasticity:** Resources can be scaled up (more power) or scaled out (more instances) based on demand.
* **Consumption-based Pricing (Pay-as-you-go):** You only pay for what you use, shifting from Capital Expenditure (CapEx) to Operational Expenditure (OpEx).

## Microsoft Azure Overview
[Microsoft Azure](https://azure.microsoft.com/) is a continually expanding set of cloud services that help organizations meet business challenges. It provides the freedom to build, manage, and deploy applications on a massive, global network.

### Key Azure Service Categories
Azure provides a broad range of services categorized mainly into:
1. **Infrastructure as a Service (IaaS):** Provides raw compute, storage, and network infrastructure. You maintain maximum control over the environment (e.g., Azure Virtual Machines, Virtual Networks).
2. **Platform as a Service (PaaS):** Provides a managed hosting environment where you deploy your applications without managing the underlying OS or infrastructure (e.g., Azure App Service).
3. **Software as a Service (SaaS):** Provides fully managed applications delivered over the web (e.g., Microsoft 365).

### AZ-104 Relevance
For the **AZ-104 Azure Administrator** exam, these fundamentals are the bedrock for the five core domains:
1. **Manage Azure identities and governance:** Microsoft Entra ID (formerly Azure AD), Role-Based Access Control (RBAC), and Azure Policies.
2. **Implement and manage storage:** Storage accounts, access tiers, and redundancy.
3. **Deploy and manage Azure compute resources:** Virtual Machines, Azure Container Instances (ACI), and App Services.
4. **Implement and manage virtual networking:** Virtual Networks (VNets), Network Security Groups (NSGs), peering, and DNS.
5. **Monitor and maintain Azure resources:** Azure Monitor, alerts, and backup/recovery.

### Security First
Before deploying any resource, understanding **Identity and Access Management** and **RBAC** is paramount. Every action in Azure requires proper access control, which is why Identity and Governance is the heaviest domain on the AZ-104 exam, accounting for 25-30% of the content.
