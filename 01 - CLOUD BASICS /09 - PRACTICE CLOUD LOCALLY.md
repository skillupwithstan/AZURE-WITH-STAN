This video explores how to practice public cloud platform services (AWS, Azure, and GCP) directly on your local laptop without needing a credit card, billing setup, or a cloud account. It introduces Floci (or Flocy), an open-source, lightweight cloud emulator tool that runs on local devices (via Docker containers) and supports over 50+ AWS services, 15 Azure services, and 8 GCP services. The session covers why local emulation is useful—especially for students and DevOps engineers learning to configure compute, databases, or Kubernetes clusters—and highlights Floci's advantages (like ultra-low memory consumption and instant setup) compared to other tools like LocalStack. Part 2 will feature the practical, step-by-step installation and hands-on usage of this tool.
